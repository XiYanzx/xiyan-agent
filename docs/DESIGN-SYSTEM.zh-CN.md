# Xiyan Design System 1.0

## 产品与场景

Xiyan 是中文 Android 协作助手，包含通用手机任务与 Galaxy 游戏两种使用场景。用户首先表达目标，然后查看回复、任务准备状态和执行反馈。账号、模型、权限和用量属于支持信息。当前已实现文字对话、模型目录、用量及手机单步验证；自主执行仍在开发。界面按实际能力和返回值呈现状态。

本轮保留原生 Java / Android View 架构、业务接口、数据模型、存储键和账号授权路线。现有消息增量更新、输入焦点与选区、账号范围检查、指定窗口截图和停止行为继续保留。

## 视觉方向

| 方向 | 特征 | 适用性与取舍 |
| --- | --- | --- |
| 青瓷 · 墨色工作台（采用） | 暖白阅读底、墨绿深色底、青瓷主色，细分隔线与紧凑工具 | 同时照顾中文阅读、对话和任务管理；青瓷色建立 Xiyan 辨识度，状态色有独立职责 |
| 蓝墨 · 精密工作台 | 冷白和深蓝中性底、钴蓝主操作，结构紧凑 | 熟悉、清晰，适合高密度管理；与上一版蓝紫色的差异较小 |
| 深空 · 指挥台 | 石墨底、紫色强调，强调游戏与任务监控 | 游戏氛围更强；长时间阅读及轻量日常场景需要更多克制 |

采用青瓷方向。商业参考分别用于对话阅读、信息密度和交互反馈，保留自有品牌和页面结构。商业产品截图仅作研究；实现采用自有布局与合法开源图标。

青瓷用于主操作、选中项和活跃状态；游戏紫只用于相关模式及第二额度窗口。绿色连接状态以实际会话为依据。红色停止只在进行中的操作出现，空闲时通过菜单继续提供停止入口。

已计算正文对背景对比度：浅色 13.73:1、深色 16.12:1；辅助文字分别至少 5.13:1、7.55:1；主按钮文字分别 4.90:1、7.84:1。正文与辅助文字目标均为 4.5:1，交互图形目标为 3:1。

### 排版

Android 采用系统 sans，中文使用系统中文字体，跟随系统字号。使用 400 / 500 / 600 字重，数字采用等宽数字特性。文档默认字体为微软雅黑。

| 层级 | 字号 / 建议行高 | 用途 |
| --- | --- | --- |
| Display | 36 / 44sp，600 | 用量总数等唯一数字中心 |
| Hero | 28 / 36sp，600 | 聊天首页短标题 |
| Title | 22 / 30sp，600 | 页面标题 |
| Section | 16 / 24sp，600 | 信息分组 |
| Body | 15–16 / 22–24sp，400 | 消息与主要内容 |
| Label | 14 / 20sp，500 | 控件与导航 |
| Caption | 12–13 / 18sp，400 | 说明、更新时间与状态 |

一个页面保留一个主要视觉中心。顶部导航标题与内容标题避免重复。说明优先一行，复杂说明放到具体状态或展开区域。

### 空间与形状

- 间距尺度：4、8、12、16、20、24、32dp；页面左右 20dp，窄屏 16dp。
- 分组间 24dp，组件间 12dp，标签与正文间 4–8dp。
- 圆角：列表选中区 12dp、按钮 14dp、内容面板 20dp、输入栏 24dp、底部面板 28dp。
- 交互区域至少 48×48dp；图标本体采用 20 或 24dp，保持统一 24 坐标系及 2 单位轮廓。
- 内容面板使用细边框和层次底色。普通按钮取消平台默认阴影；输入栏最多使用轻微抬升。
- 宽屏内容上限约 760dp，居中显示；高度缩小时保留关键输入和停止入口。

## 组件

### 操作层级

主操作采用青瓷实色，同屏同区域保持一个主要操作。次操作采用轮廓或浅底。复制、编辑、查看详情等采用文字或小图标操作。胶囊选择器的视觉高度和填充弱于主按钮，点击区域仍为 48dp。

所有组件具有 pressed ripple、焦点、disabled、selected 和忙碌状态。禁用状态同时通过可用性、文字和外观表达。行项目在可点击父节点提供完整名称；装饰图标留在辅助技术阅读顺序之外。

### 状态

加载显示实际操作名称与小型进度反馈，保留取消入口。空状态用一处简短标题和明确下一步。错误状态显示可读原因与重试动作，辅助信息按需要展开。成功反馈采用轻量状态文字或图标。

账号、周期额度、token 统计分别表达各自状态。缺失百分比使用 `—`；最近调用数字来自完成响应，保留原时间。合成状态样例集中在 debug 组件预览中并清楚标识。

### 图标与品牌

功能图标统一采用 Lucide，固定上游版本，保留 ISC 及相关 MIT 许可和逐项来源。原始 SVG 与派生 Android VectorDrawable 分别记录散列。颜色由语义 token 提供。品牌标记采用自有交汇式 X 图形，与启动图标、导航及关于页保持一致。

## 页面布局

| 页面 | 视觉中心与组织 |
| --- | --- |
| 聊天 | 简短、同轴的欢迎内容，少量紧凑建议；固定输入栏；回复正文留出阅读空间，复制与编辑采用弱操作 |
| 任务 | 紧凑任务空态，两种任务草稿入口；真实准备项采用状态列表，避免重复介绍段落 |
| 模型 | 搜索、账户模型列表、独立思考选择；选中标记清楚，应用动作明确；小高度下表单整体滚动 |
| 用量 | 最近完成调用的总数居首，输入/输出并列；细分项为次级列表，未知周期额度使用简短信息区 |
| 账号 | 单个账号摘要与真实连接状态，连接/续期为主操作；环境和退出操作分组 |
| 设置 | 紧凑分组列表，当前选择作为行尾值；外观页展示可理解的浅深主题预览 |
| 手机控制 | 权限状态和管理入口居首，停止与验证工具按用途分组 |
| 关于 | 品牌、版本、当前能力和开源信息，控制说明长度 |
| 开发者 / 测试台 | 使用相同文字、颜色和控件；测试画布保留测量用途的几何与行为 |

侧栏以单行导航为主，当前页明显选中。底部账号摘要显示真实连接或读数状态。短视口键盘模式隐藏欢迎与辅助消息内容，保留导航、输入及发送/停止的完整工具行。

## 动效

- 页面进入：180ms，透明度与最多 8dp 位移。
- Android 11+ 的键盘开合由 `WindowInsetsAnimation` 同步可用空间，结束与取消后恢复最终 Insets；保留同一个输入框。Android 10 沿用窗口 Insets 布局。
- 侧栏展开/关闭：220ms；遮罩同步变化，快速重复点击受状态保护。
- 选择和按钮按下：使用系统 ripple；异步回复增量更新保持稳定。
- 尊重系统关闭动画的设置。输入焦点、光标与正在进行的授权事务随页面生命周期保留。

## 视觉验收

每页检查视觉中心、排版、间距比例、颜色对比、图标与组件、反馈、尺寸适配，以及加载/空/错误状态。采用模拟器实际运行截图。至少覆盖浅色、深色、320dp 窄屏、1.3 倍字号、横屏键盘和正常竖屏。

独立 Reviewer 根据实际截图列出问题；修复后获取新截图再次审查。验收记录区分实际状态、合成组件状态、代码检查和后续待测内容。页面存在截断、主要操作不可达、状态误导或明显层级冲突时继续修正。
