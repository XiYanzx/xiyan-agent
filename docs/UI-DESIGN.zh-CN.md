# Xiyan Agent 界面设计

## 设计目标

首页首先回答三个问题：当前有没有任务、账号与手机控制是否连接、下一步可以做什么。对话、任务和设置各有独立入口，开发测试信息集中到开发者页面。

本轮实现为原生 Android Java 界面。账号连接来自 `SiwcClient` 的实时状态；模型目录来自本次账户接口响应。任务引擎与实际推理仍待验证，任务页面展示真实空态，暂停与恢复保持禁用。对话页提供本机草稿；账号与模型就绪后，用户可手动发起文本请求，并查看流式响应与完成、失败或取消状态。本轮实际覆盖范围由运行报告记录。

## 信息结构

| 入口 | 主要内容 | 可执行操作 |
| --- | --- | --- |
| 首页 | 账号与手机控制状态、任务空态、通用及游戏模式 | 查看连接条件、保存模式偏好、进入草稿 |
| 对话 | 任务说明模板、草稿输入、模型响应 | 编辑和保存本机草稿；账号与模型就绪后手动发送文本 |
| 任务 | 当前任务空态、执行准备、暂停与恢复位置 | 查看连接条件、返回草稿、停止 |
| 设置 | 账号入口、主题、手机权限、版本与开源项目 | 选择主题、打开系统权限、进入开发者页面 |
| 账号与模型 | 本机会话、连接反馈、目录来源和时间、模型思考参数 | 连接环境检查、用户主动登录、刷新目录、保存模型偏好、退出 |
| 开发者与诊断 | 运行环境、控制测试台、来源提交、近期事件 | 单步控制验证、停止、导出诊断 |

停止入口固定在主界面底部，导航切换和正文滚动时仍可见。它撤销后续手机控制授权，并取消当前连接操作。已派发短手势的结束状态继续遵循现有控制层行为。

## 视觉规范

界面使用深石墨与青绿，也提供浅色主题。默认跟随系统；用户可以在设置中选择深色或浅色。主内容在宽屏上居中，最大宽度为 680dp。

| 项目 | 采用值 |
| --- | --- |
| 页边距 | 20dp |
| 常用间距 | 8、10、12、14、20、24dp |
| 卡片圆角 | 24dp；模式卡片 22dp |
| 操作按钮圆角 | 16dp |
| 页面标题 / 卡片标题 / 正文 / 说明 | 28 / 20 / 16 或 14 / 13 或 12sp |
| 操作触控区域 | 按钮最小高度 50dp；导航最小高度 68dp |
| 深色背景 / 卡片 | `#0C1218` / `#172029` |
| 深色强调 / 主文字 | `#74E6CD` / `#EEF4F6` |
| 浅色背景 / 卡片 | `#F3F7F7` / `#FFFFFF` |
| 浅色强调 / 主文字 | `#006C5B` / `#182D34` |

Android 界面使用设备系统 `sans` 字体，字号采用 sp，保留系统字体缩放。文档的排版默认字体为微软雅黑；Markdown 的实际字体由阅读器决定。应用资源使用 Android 自带字体与项目原创的线条图标，不随包分发 Windows 字体文件。

原有控制测试台保留深色测试表面、指定窗口截图与回调失效处理。图标由 `AgentIconView` 本地绘制，首页的轨道图形为静态原创图形。运行状态尚未发生时，页面保持静止。

## 真实状态与交互

- `snapshot.hasSession` 表示存在经过验证并保存的本机会话；`snapshot.connected` 还检查本地有效期与重新授权状态。页面分别展示尚未登录、本机会话有效、已过期或需要重登，网络调用前再次检查。
- 本机会话过期时保留显式登录入口，用户可以重新连接；会话存在时仍提供退出入口。刷新入口遵循运行时的授权与有效期检查。
- 模型目录尚未获取、真实空目录、服务端声明不可用与连接失败分别呈现。思考选项直接读取每个模型的元数据，未提供的选项保持未提供。
- 用户选择模型后仅保存本机偏好，提示实际推理仍待验证。
- 模型选择弹窗提交时重新检查当前账号、目录引用与操作状态；目录刷新后重新校验保存的思考选项。发送操作只接受当前账号最新目录中的有效选择。
- 文本推理只有收到正式完成事件后才显示本次回复完成。取消或失败时保留对应状态，草稿与回复内容留在诊断报告之外。
- 登录由明确按钮发起，说明弹窗后打开系统浏览器。用户自行完成官方登录和授权，应用接收本机回调。
- 用量缺少已验证读数时，显示等待官方额度读数，并提供官方用量页面。
- 草稿最多 4000 字，显式保存到应用私有偏好。诊断导出保留版本与应用事件，草稿内容留在报告之外。
- 所有主要按钮具有文字标签；原创装饰图标退出无障碍焦点。底部导航向无障碍服务提供按钮角色及选中状态。
