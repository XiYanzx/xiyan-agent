# Xiyan Agent 界面改版与用量设计

2026-11-02，Asia/Shanghai。用户要求参考 Mobile Codex，改善页面拥挤、功能入口难找和配色单调的问题，并直接展示官方百分比与使用量。本文件记录本轮采用的方案，实际安装包与数据支持情况由本轮模拟器报告验收。

## 页面结构

启动后直接进入对话。顶部工具栏显示当前页面和导航，连接状态放在账号与用量页；中间消息区独立滚动，底部固定输入栏。空态只保留简短欢迎和少量可选提示，输入区、回复和任务说明分清主次。

| 目的地 | 主要内容与操作 |
| --- | --- |
| 对话 | 消息、可增长输入框、模式与模型摘要、发送；响应时发送原位变为停止 |
| 侧栏 | 当前对话、任务、模型、账号与用量、设置；底部放账号和紧凑额度摘要 |
| 模型 | 搜索与实际账户列表；模型、思考程度分步选择，保留当前偏好 |
| 任务 | 独立列表和真实空态；当前阶段清楚说明手机自动操作的准备状态 |
| 账号与用量 | 连接、官方周期百分比与重置时间、最近调用 token 统计、数据更新时间 |
| 设置 | 外观、手机控制、开发者诊断及关于等分组入口 |

全局底部大停止条与四项底导航收回到当前操作所在位置。对话运行时保留明显的停止按钮；切到其他页面后，工具栏继续提供停止入口。停止仍撤销手机控制并取消账号操作。

## 配色与排版

采用 Xiyan 自有的浅色和深色方案，跟随系统或由用户选择。蓝色承载主要操作，紫色标识游戏和第二用量窗口，青色表示连接与完成，琥珀提示注意事项，红色用于停止与失败。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 / 侧栏 | `#F7F8FC` / `#EEF2FF` | `#0F1524` / `#141D31` |
| 主色 | `#5266ED` | `#98A6FF` |
| 紫色 | `#865DE5` | `#BC9EFF` |
| 青色 | `#098F87` | `#6EDBCB` |
| 琥珀 | `#B87014` | `#F3C769` |
| 停止 | `#C94459` | `#FF9CAD` |

页面标题约 22sp，分组标题 16sp，聊天正文 16sp，辅助文字 13sp。间距使用 4、8、12、16、24dp，页边距 16dp；列表行约 56–64dp，交互区域至少 48dp。侧栏宽度约为屏幕的 86%，上限 320dp。系统字号放大和键盘出现时继续保留主要操作。

模型表单整体滚动，首次打开空目录时获取一次真实列表。键盘挤压可用高度时，聊天收成菜单、输入和发送/停止的紧凑工具行，保留同一个输入框与选区。开发构建已在 320dp 窄屏、1.3 倍字号和横屏键盘组合下复验：模型应用按钮可滚动到达，聊天发送区域完整可见。最终安装包继续复验并随附件记录。

Android 使用系统 sans 字体与项目自绘图形。中文说明按 humanizer-zh 核对，文档默认排版字体为微软雅黑；Markdown 字体由阅读器设置决定。

## 官方用量

周期额度与单次 token 分区呈现。窗口百分比只采用当前账号实际收到的官方数值，显示已用与剩余、真实窗口长度、重置时间、来源和更新时间。缺少读数时使用 `—` 与简短原因；旧读数保留原观测时间并标记过期，真实 0% 继续显示为 0%。

token 区标题为“最近一次完成调用”，展示官方响应中的 input、output、total；缓存和推理 token 作为明细，保留完成时间。明细属于子项，不重复累加。字段缺失时保留未知。

本应用继续使用自己的 SIWC 授权及公开 Responses 路线。可采用实际响应的官方额度头、`codex.rate_limits` 事件和 `response.usage`。独立百分比查询接口的支持情况继续核对；用量页提供官方 Usage 入口。数据绑定本应用当前账号，退出或账号变更清除旧数据，迟到的旧操作继续受代际检查保护。

## 保留的交互与安全行为

保留 MainActivity 名称及原有草稿、模式、模型和主题存储键。切页、打开选择面板、旋转和换主题前保存当前草稿状态，导航不触发发送。账号观察者按页面生命周期订阅，离开页面继续保留尚在进行的官方登录。

流式更新只刷新消息与状态，输入框维持焦点、光标和当前编辑内容。用户查看先前文本时保留阅读位置。模型选择继续检查当前目录引用、账号范围、连接与忙碌状态；接口拒绝思考参数时显示实际错误，保留用户选择。

控制测试台、指定窗口截图、清除与迟到回调释放逻辑保持独立。开发者信息集中到诊断入口。任务及历史列表采用实际数据，当前阶段的空态保持明确。
