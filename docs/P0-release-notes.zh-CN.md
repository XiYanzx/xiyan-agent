# Xiyan Agent 0.1.0-p0.9 技术预览

此 APK 是手机控制与运行环境的技术验证工具，**尚无自主 Agent 能力，P0 尚未验收**。

新版采用“青瓷 · 墨色工作台”：暖白阅读底、墨绿深色底和青瓷主操作，统一字体、留白、圆角、图标、弹窗与动效。聊天、任务、模型、账号、用量和设置按用途分别组织，调试内容集中到开发者页面。输入栏固定，生成时发送原位变为停止，失败后提供原因、编辑与手动重试；思考参数错误可直接进入选择面板。Android 11+ 键盘过渡同步输入区，窄屏和横屏键盘保留完整操作。完整设计规范与分阶段证据见 `docs/DESIGN-SYSTEM.zh-CN.md` 和 `docs/UI-DESIGN-QUALITY-P0.9.zh-CN.md`。

用量页突出最近完成调用的总数、输入与输出，细项和更新时间位于第二层。周期百分比、重置时间和额外 Credits 按官方实际字段呈现；缺少有效周期读数时显示 `—` 和原因。真实零值与旧读数分别处理，每个窗口保留自己的来源、观测时间与过期状态；账号变更和退出清空旧记录。P0.9 第一轮开发构建取得八个模型，真实 Sol/default 请求输入 36、输出 18、合计 54 token；最终干净提交的实际数字、完整测试及独立视觉验收见同一 Release 附件。

33 项功能图标来自固定版本 Lucide，原始 SVG、派生资源散列和完整 ISC/相关 MIT 许可随源码保存，APK 内含完整许可文本；Xiyan 交汇式 X 品牌为原创。商业产品截图仅用于研究，发布包提供本应用模拟器实拍。

既有订阅请求修复继续保留：消息数组格式、省略不支持的 `max_output_tokens`、标准服务等级与本地响应上限，以及受限错误分类、实际响应模型、服务等级证据和登录阶段反馈。

模型目录解析补齐官方 `supported_reasoning_levels`、`default_reasoning_level` 与选项 `effort` 字段。类型、默认值声明和模型选择继续严格校验；失败诊断仅记录白名单结构和固定原因，实际目录结果见对应安装包的验证记录。

服务等级对象兼容实际目录使用的 `id` 字段。读取服务端选项后，推理请求仍固定 `service_tier: default`。

模拟器实测中，连接读取到空 Content-Type。此时客户端继续严格校验有界 SSE；显式非 SSE MIME 继续拒绝，完整 `response.completed`、完成状态及无错误仍为成功条件。新增安全流结构诊断，保留实际响应模型、服务等级与耗时。

真实账号验证使用 debug 专用的同进程入口，保留进行中的登录事务；登录忙碌时只读取状态。入口受系统 DUMP 权限保护，结果仅写入应用私有目录并排除身份和凭据，release 构建排除该入口。合成密钥库 instrumentation 测试单独运行，安排在账号操作空闲时。

用户在系统浏览器明确授权后，应用保存经签名验证的会话；令牌由 AndroidKeyStore 加密保存在应用私有目录。模拟器已完成会话保存与更新后恢复、八个展示模型读取，以及 Sol 的标准等级合成推理。请求使用官方 HTTPS、`store:false`、`stream:true`；目录中的 Ultra 本次被推理接口以 HTTP 400 拒绝，服务默认思考值实测通过。最终安装包复验结果见发布附件；令牌轮换、退出撤销和完整自主任务继续验收。

窗口截图在 API29–33 明确禁用，不回退整屏。清除、停止或退出会撤销待返回的截图，迟到图像被释放。分屏及覆盖层的设备像素隔离仍待验证；本版图像只作预览，不直接映射动作坐标。

纯 Java 核心具有动作安全门与动态模型元数据解析器及单元测试；当前 Android 控制器使用独立 P0 guard，尚未整合该核心。测试不代表真实账户目录、手机控制或长周期任务已通过。

主 APK 尚未内嵌 Codex app-server/code-mode-host。先前独立探针在 Android 15 x86_64 模拟器的初始化、V8 和 MCP 回合均未通过，退出码为 159。历史 ARM64 真机记录单独保留，本轮设备验证限定模拟器。周期额度百分比、通用自主任务、游戏策略、恢复监督器、Android 10 MediaProjection 及 30/60/120 分钟测试继续待验收。运行时路线见 `docs/runtime/`，本轮记录见 `docs/testing/work-local-2026-11-02.md`。

安装包使用 **Android 调试测试证书**，包名 `io.xiyan.agent.p0`，与未来正式应用隔离。此证书仅验证本次 APK 完整性，并非正式发行身份；本地与历史云端构建的调试证书可能不同，覆盖安装失败时需要卸载旧 P0。正式签名密钥尚未配置。本次发布从本地 Windows 干净源码构建；不使用 GitHub Actions。

从本 Release 下载 APK、`SHA256SUMS.txt`、`APK-SIGNATURE.txt` 和 `BUILD-INFO.json`。`sha256sum -c SHA256SUMS.txt` 可核对下载文件。GitHub 的 Source code 压缩包是本 tag 的对应源码；构建方式见 `docs/build.zh-CN.md`。请按 `docs/install.zh-CN.md` 在手机手动授权和记录验证结果，勿将模拟器截图当作真机证据。
