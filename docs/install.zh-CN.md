# P0 安装与手机验证

此版是技术验证工具，未接入账号和推理，不会自主执行通用或游戏任务。最低 Android 10；本 P0 的窗口截图需要 Android 14+。APK 不包含 native runtime，可在 ARM64 设备安装，也可在其他 Android ABI 的模拟器测试 Java 层；这不代表 Codex ARM64 兼容性通过。

1. 从本仓库 GitHub Release 下载 `xiyan-agent-0.1.0-p0-debug.apk`，对照该 Release 的 SHA256 与签名报告。只安装确认来源的文件。
2. 在手机文件管理器打开 APK，由系统提示允许本次来源安装。P0 包名为 `io.xiyan.agent.p0`，使用调试测试证书；不是生产签名。
3. 打开 Xiyan Agent。首页会显示真实 API、ABI、系统页大小与服务连接状态。模型、额度和账户仍为未连接或未知。
4. 点击“打开无障碍设置”，在系统中找到 Xiyan Agent · P0，阅读用途后手动开启。部分侧载设备会显示系统受限设置提示，由用户在系统界面处理，应用不会自动绕过。
5. 返回应用，进入“手机控制测试台”。先读取窗口元数据；Android 14+ 可抓取本应用测试窗口截图并在内存预览，点击“清除截图”即可释放，离开页面也会清除。截图不会保存或上传。
6. 将“点击目标区域”完整滚动到屏幕内，点击“授权并验证一次点击”。按钮坐标来自本页实际布局；目标计数恰好增加 1 才标记复核通过。滑动区域也需完整可见，以实际滚动位置确认结果。
7. 测试“紧急停止”、退出测试页、旋转屏幕与系统关闭无障碍服务。后续动作必须重新观察和单步授权。Android 无障碍 API 不能保证撤回已被系统接收的手势，本版动作限制为短手势。
8. 首页导出本机诊断 JSON，自行选择保存位置。报告含版本、系统 API/ABI 与应用事件，不含截图或 UI 文本。请先检查再决定是否公开分享。

权限仅用于上述本机测试。可以随时在系统关闭无障碍服务或卸载应用。应用不申请互联网、存储、悬浮窗和电池优化豁免权限。

请在记录中注明 APK SHA256、版本、手机型号、Android build、测试时间、每一步实际结果及失败提示。云端模拟器证据独立放在 `docs/testing/`；iQOO/Galaxy 真机验收尚待实际执行，不应据此跳过 P0。

下一版若调试证书不同，Android 会拒绝覆盖安装。卸载旧 P0 后重新安装会清除本机事件。正式发行前另行安全配置稳定签名身份，不复用测试证书。
