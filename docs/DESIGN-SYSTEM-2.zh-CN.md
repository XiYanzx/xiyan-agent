# Xiyan Design System 2.0

文档展示字体：微软雅黑。方案：**XIYAN / 现场笔记**。本规范对应 P0.10 的黑白编辑式界面，整理日期为 2026-11-03。

## 定位与历史

用强排版、单一橙色和清楚的行列建立 Xiyan 的辨识度。用户进入首页后，先看到品牌和一句行动提示，再把注意力放到输入、回复与下一步。任务、模型、账号和用量各有独立页面，侧栏负责组织入口。

本规范接续 [Design System 1.0](DESIGN-SYSTEM.zh-CN.md)。1.0 的青瓷方案及 P0.9 验收记录保留，供历史版本追溯；2.0 是本轮统一实现依据。运行仍采用原生 Java / Android View，沿用 Android 10+、草稿、账号授权、模型目录和有限控制接口。

## 视觉方向

| 方向 | 具体特征 | 本轮选择 |
| --- | --- | --- |
| XIYAN / 现场笔记 | 黑白阅读面、大品牌字样、等宽小编号、橙色细标记、平面列表 | 采用。排版形成中心，输入与回复成为主要内容 |
| 精密工作台 | 钴蓝主操作、紧密工具栏、偏软件仪表盘的秩序 | 留作研究，信息效率较高，品牌差异较弱 |
| 深色指挥台 | 大面积石墨底、发光强调和游戏感状态 | 留作研究，日常长文阅读与普通手机任务需要更轻的表达 |

首页使用 `XIYAN.` 与“你的下一步。”建立识别。`01 / 现场笔记` 等小编号指向页面分组；执行状态另用真实状态文字说明。布局以文字、分隔线和留白分组，减少逐段包裹的大卡片。

## 排版

Android 使用系统 sans 和系统中文字体，随系统字号缩放。标题使用 700 字重，标签及导航使用 500，正文使用 400。小编号采用系统等宽字体；用量数字启用等宽数字特性。文档展示使用微软雅黑，应用随系统提供的字体显示。

| 层级 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| Brand | 52sp / 700 | 无回复、无草稿且空间充足的首页 `XIYAN.` |
| Brand compact | 32sp / 700 | 侧栏品牌 |
| Page / Hero | 28sp / 700 | 页面标题与“你的下一步。” |
| Current draft | 20sp / 700 | 有草稿时收敛后的首页提示 |
| Section | 16sp / 700 | 页面分组和作者标签 |
| Body | 15–16sp / 400 | 消息、主要说明、输入 |
| Action | 14sp / 500 | 按钮与常规操作 |
| Caption / Index | 11–13sp / 400 或 500 | 编号、时间、状态和辅助说明 |
| Usage display | 52sp / 700 | 最近一次完成调用的总量中心 |

常规 22sp 及以上文字行高约为字号的 1.3 倍，其余约为 1.5 倍；首页 52sp 品牌字样使用 56sp 行高。标题适量收紧字距；中文正文保留自然字距。每页突出一个中心，工具栏与正文标题按内容分工。

## 空间与形状

- 基础间距：4、8、12、16、20、24、32dp。页面左右 20dp，窄屏 16dp；宽屏内容上限 760dp。
- 页面分组优先使用 1dp 分隔线与 20–24dp 留白。内容容器圆角 0–4dp，按钮 8dp，输入栏 10dp，面板 12dp。
- 按钮取消平台默认阴影与 elevation。表面层次依靠边框、颜色和位置，保留 pressed ripple 与键盘焦点反馈。
- 图标本体 24dp，统一 24 单位坐标和 2 单位圆端线条；下拉标识 14dp。可交互区域至少 48×48dp，视觉尺寸与点击范围分别检查。
- 输入框同时设置 minHeight 和 minimumHeight 48dp。普通列表行至少 56dp，模型候选至少 60dp，双行说明允许自然增高。

## 组件

### 操作与反馈

主操作使用橙色实底；次操作使用轻底或轮廓；复制、编辑、详情及导航使用文字或图标操作。当前模型已应用时显示清楚的状态文字，面板保留“完成”；候选改变后显示“应用选择”。禁用项仍保留可读文字和原因。

加载指示只跟随实际操作。模型目录读取使用小进度条与具体文案；其他操作忙碌时显示对应状态。失败先说明原因，再给用户可执行的手动下一步。思考程度被服务拒绝时提供“更改思考程度”；选择保持用户设置，重试由用户触发。

### 品牌、图标与材料

`XIYAN.` 字标、自有 X 图形及橙色标记共同形成品牌。功能图标使用既有 Lucide 资源，固定修订 `a529c28a8782e7954dde3d1a5e4409e829242b86`，共 33 项。保留完整 ISC 及所列 Feather 派生图标的 MIT 许可、原 SVG 和 Android 派生散列，见[来源清单](../third_party/lucide/PROVENANCE.json)与[第三方声明](../THIRD_PARTY_NOTICES.md)。

商业产品页面只作设计研究。实际布局由原生组件实现，品牌采用自有内容；开源图标按固定来源和许可分发。

## 页面布局

| 页面 | 版式中心 | 主要行为与真实状态 |
| --- | --- | --- |
| 对话 | `XIYAN.`、行动短句、两条编号建议与固定输入栏 | 欢迎区域按可用高度平衡；有草稿时收敛；已有回复时进入正文阅读。用户提问用作者行和细橙线，回复采用阅读正文，复制/编辑为弱操作 |
| 任务 | 执行清单式标题、两条编号草稿入口与准备项 | 展示当前草稿、手机任务与 Galaxy 游戏入口；账号、模型和无障碍列出实际准备状态；Shizuku 由手机控制页展开，自主执行明确标为待接入 |
| 模型 | 搜索、账号候选列表、当前选择与思考程度 | 搜索输入保持稳定；当前与待应用明确区分；服务默认值完整显示于面板。首次空目录可在已保存会话且空闲时检查一次 |
| 账号 | 单个账号摘要和连接动作 | 本机会话、续期、重新连接、恢复本次连接与手动回调按真实状态出现。辅助选项收纳到次级入口 |
| 用量 | 最近一次完成调用总数，输入/输出并列 | 缓存与推理数字列为子项，保留采集时间。周期百分比未知使用 `—`；检查后无有效读数时说明“本次未取得有效额度读数” |
| 手机控制 | 无障碍与 Shizuku 分组状态、手动授权/连接、有限验证 | 实际运行身份、忙碌、停止与单步结果清楚可见；命令完成后继续核对目标效果 |
| 设置 | 紧凑分组列表，当前值位于行尾 | 外观、控制、开发者和关于各自可达；技术诊断收纳到开发者页面 |
| 侧栏 | `XIYAN.`、小号目录编号、平面导航行 | 当前页用橙色细条、字重和语义选中表达。只显示当前对话/草稿及真实账号、用量摘要 |

## 输入、键盘与生命周期

同一个 EditText 承载草稿，流式增量更新只替换已有回复内容，保留焦点、选区和输入法。自动跟随回复使用纯位置滚动；用户上滚阅读时保留当前位置。页面切换、旋转和主题变更继续沿用原草稿键和选择状态。

短高度模式依据实际可用视口切换，收起欢迎、消息区和辅助工具，保留完整的 48dp 菜单、输入与发送/停止。空间允许时补一行当前语境。高度恢复后沿用原输入框及草稿。模型表单采用整体可滚动结构，横屏、键盘和 1.3 倍字号下搜索、候选、思考程度与应用仍需完整可达。

导航和浏览器跳转按生命周期退订观察者；登录事务继续由账号层及用户发起的前台服务管理。停止同时请求账号操作取消、无障碍 emergencyStop 和 Shizuku stop。已派发短手势继续受有界结束与后续画面核对约束，界面显示相应提示。

暂停或失败后的继续、编辑重试均保留原提问；已有另一份草稿时先确认，用户可取消并保留当前输入。当前文字调用为单回合，侧栏和页面按实际记录展示内容。

## 动效与无障碍

页面进入 180ms，侧栏 220ms；位移保持轻微，按下使用系统 ripple，尊重系统动画开关。Android 11+ 键盘动画同步窗口 Insets，Android 10 使用对应窗口布局路径。转场结束、取消及快速重复操作均回到确定状态。

标题标记为无障碍标题；可点击行提供完整名称和当前值；装饰性编号/图标退出朗读顺序。错误原因与更新状态使用适度的 live region。视觉检查同时核对触控几何、系统字号、截断、焦点及停止入口。

## 独立验收

主 Agent 统一构建并在专用模拟器获取真实截图；独立 Reviewer 检查其他实现者的页面，修复后使用新截图复核。每张图记录来源构建与真实状态，合成样例明确标注。

验收至少覆盖浅色、深色、320dp 窄屏、1.3 倍字号、横屏键盘、普通竖屏，以及无草稿/有草稿/流式回复/取消/失败。模型页核对搜索、思考选择和应用可达；账号页核对未登录、已保存会话和可恢复登录；用量页分别检查真实数字、零值、未知与旧读数。

本规范定义验收要求。P0.10 的最终截图结论、测试总数、来源提交与安装包记录由最终阶段报告确认；旧版截图继续归属对应版本。
